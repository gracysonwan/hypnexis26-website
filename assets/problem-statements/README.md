# Problem statement PDFs

The Problem Statements section on the home page goes live by itself once a PDF
with the exact name below is uploaded to this folder **and** its release time
has passed. No code changes are needed.

| Release | Time (IST) | Upload this file here |
|---|---|---|
| Problem Statements | 24 Oct 2026, 11:30 AM | `hypnexis26-problem-statements.pdf` |
| Additional Problem Statements | 24 Oct 2026, 6:15 PM | `hypnexis26-additional-problem-statements.pdf` |

Notes:

- The name must match exactly (all lowercase, hyphens, `.pdf`).
- Once uploaded and deployed, the file can be opened by anyone who has its
  direct link, even before the countdown ends. Upload it at release time if
  the statements must stay secret until then.
- Deploying takes a couple of minutes. Until the file is live, the section
  shows "Publishing" and checks again every 15 seconds, so visitors don't
  need to refresh.
- To change a release time or file name, edit `PS_RELEASES` near the bottom
  of `hypnexis-main.html`.
